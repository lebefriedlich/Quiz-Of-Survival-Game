# Quiz-Of-Survival-Game

A Unity project archived for development and build on Windows. This README covers setup, structure, and how to build and run.

## Requirements
- Unity Editor: 2022.3.48f1 (LTS)
- Windows 10/11
- Visual Studio 2022 (for C# scripting and .sln)
- .NET Framework and runtime installed by Unity (handled automatically)

## Getting Started
1. Install Unity Hub and add Unity `2022.3.48f1`.
2. In Unity Hub, click "Open" and select the project folder:
   - `d:\Project\Quiz-Of-Survival-Game`
3. Let Unity import assets and compile scripts (first open may take time).

## Opening and Running
- In Unity, open the target scene:
  - `MainMenu.unity` or `GamePlay.unity` via [Assets/Scenes](Assets/Scenes)
- Press Play in the Unity editor to run.

## Build (Windows Standalone)
1. Open Build Settings: `File → Build Settings…`
2. Add scenes in build: drag `MainMenu.unity`, `GamePlay.unity`, `latar.unity` into Scenes In Build.
3. Select `PC, Mac & Linux Standalone` → `Windows`.
4. Set Architecture (x86_64 recommended) and click `Build`.
5. Choose an output folder (e.g., `Build/Windows`). Unity will generate the executable and the `Project Game_Data` folder.

## Troubleshooting
- Editor version mismatch:
  - If Unity prompts to upgrade/downgrade, install `2022.3.48f1` via Unity Hub.
- Missing packages or compile errors:
  - Open [Packages/manifest.json](Packages/manifest.json) to verify packages; use `Window → Package Manager` to resolve.
- Import performance:
  - First open can be slow due to Library generation. Avoid deleting the [Library](Library) folder unless necessary.
- Audio issues:
  - Check mixers: [Assets/MainMixer.mixer](Assets/MainMixer.mixer), [Assets/GamePlayMixer.mixer](Assets/GamePlayMixer.mixer).
- Scene not in build:
  - Ensure scenes in [Assets/Scenes](Assets/Scenes) are added in Build Settings.
